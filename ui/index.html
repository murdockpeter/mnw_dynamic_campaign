Design Notes

Why This UI Exists Now

The point of this UI scaffold is not presentation polish alone. It is a contract surface. If the backend changes shape, this screen should need to change too. That pressure keeps the persistence architecture honest and human-usable.

The later desktop-app step should wrap this UI rather than replace it. That is why the structure is web-native and Tauri-friendly from the start.

Scope

What This Debug View Is For

The Norway theater is not meant to place every unit into every mission. This page shows the larger operational cross section so you can sanity-check corridor geometry, sector ownership, and where persistent forces are generally assumed to be operating.

The ORBAT markers represent developer-level theater bookkeeping, not exact tactical truth. Scenario generation can still pull only a subset of this picture into a mission package.

Interpretation

Operational ORBAT Overlay

Each ORBAT marker sits on a sector center, not on a literal tracked contact. The intent is to expose the assumed theater distribution for debugging continuation logic, persistence, and force-selection behavior.

The flattened KML export includes both route geometry and ORBAT placemarks so the same debugging picture can move into Google Earth or any other KML-capable viewer without relying on nested folders.

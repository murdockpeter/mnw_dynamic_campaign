South China Sea SLOC Google Map

This page renders the exact South China Sea route variants from shared/campaign-generator.mjs as Google Maps polylines and labeled markers. It does not use KML import, so it avoids the deprecated Google KML overlay path.

Setup

Load Your Google Maps API Key

Enter a browser-safe Google Maps JavaScript API key, or pass it in the URL as ?apiKey=YOUR_KEY. The page stores the key in local browser storage so you do not have to re-enter it every time.

Behavior

What This Page Draws

Each variant gets four route layers: player, enemy, support, and air.

Markers are labeled with the same waypoint naming convention used in the SVG map: PLAYER-1, ENEMY-2, and so on.

The map auto-fits to all route points after load.
